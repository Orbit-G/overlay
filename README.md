## 🚀 About Overlay

**Overlay** is a lightweight AI-powered desktop application built to assist with interview preparation, coding practice, and technical problem solving.

It provides a distraction-free overlay that can stay on top of your workspace while you continue working in your IDE, browser, or other applications.

### ✨ Highlights

* 🖥️ **Desktop AI Overlay** — Access AI assistance without constantly switching windows.
* 📸 **Screenshot Analysis** — Capture questions or content directly from your screen.
* 🤖 **AI-Powered Answers** — Get contextual responses from AI models.
* ⚡ **Fast & Lightweight** — Designed to stay responsive while running in the background.
* 🎯 **Interview Preparation** — Useful for coding, technical, and general interview practice.
* 🔒 **Privacy Focused** — Built with privacy and minimal data exposure in mind.
* 🪟 **Always-on-Top** — Keep Overlay accessible while working in other applications.

## 🛠️ Tech Stack

Overlay is built using modern desktop and AI technologies.

| Technology           | Purpose                                      |
| -------------------- | -------------------------------------------- |
| **Electron.js**      | Cross-platform desktop application framework |
| **JavaScript**       | Application logic                            |
| **HTML5 / CSS3**     | User interface                               |
| **Node.js**          | Backend/runtime functionality                |
| **AI APIs**          | Intelligent question analysis and responses  |
| **Screenshot & OCR** | Screen capture and content extraction        |
| **Electron IPC**     | Secure communication between processes       |
